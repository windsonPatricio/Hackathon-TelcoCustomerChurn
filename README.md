# Front-End - ReterMais

O seguinte projeto utiliza a tecnica de Single Page Aplication (SPA) 
e biblioteca bootstrap para elementos. 

### Requisições: 

O arquivo ```js/api.js``` utiliza das funções ```montarPayload()``` e ```preverCancelamento()```
para realizar as requisições ao ```URL```  do ```back-end```.

### Atencão:

Ajuste a ```URL``` para realizar seus testes.
